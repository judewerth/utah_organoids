# Utah Organoids DataJoint Pipelines

### Pipeline Overview

<img align=right width="413" height="459" alt="Screenshot 2026-01-05 at 1 43 27 PM" src="https://github.com/user-attachments/assets/0e239843-5245-44aa-aaad-1e2f5a49928b" />

- Organization and storage for electrophysiology recordings
- Automatic processsing of MUA data (done on a per file basis)
- Functionality to extract active time frames across long recordings
- Analyses intiated by manual entry (or by frame functionality):
     -  MUA:
          -  MUA spike metrics
          -  Population spike bursts
     -  LFP:
          -  LFP traces and spectrograms
          -  Power band metrics
          -  FOOOF metrics
          -  Coherence
          -  Cross Frequency Coupling
     -  Single Units:
          -  Single unit spike metrics
          -  Spike Time Tiling Coefficient (STTC)
